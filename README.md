## 一、研究名表看什么

不是只看价格，而是看四条线：
1. **品牌谱系**：顶级制表 / 传统名表 / 独立制表 / 时装表 / 智能表。
2. **机芯**：自动机械 / 手动机械 / 石英 / Spring Drive / 陀飞轮。
3. **风格**：正装 / 运动 / 潜水 / 珠宝 / 复杂功能。
4. **审美参数**：表径、厚度、表盘颜色、表带、金属色，是否适合你的手腕。

> 表既是工具，也是风格表达——和穿搭、配饰联动看。

## 四、审美参数 & 预算

- **表径**：手腕细选 36-38mm，粗犷选 40-44mm。
- **厚度**：正装要薄（<10mm），运动可厚。
- **表盘**：白/黑/蓝百搭，绿/特殊色更个性。
- **表带**：皮带优雅、金属链耐用、橡胶运动。
- **金属色**：钢/金/玫瑰金，与肤色衣橱一致。

| 档位 | 价格 | 代表 |
| --- | --- | --- |
| 入门机械 | 1k-5k | 精工、浪琴入门、卡西欧 |
| 中端 | 5k-3w | 浪琴、欧米茄 |
| 高端 | 3w-15w | 劳力士、卡地亚、积家 |
| 收藏级 | 15w+ | 百达翡丽、AP、江诗丹顿、RM |
