## 研究名表看什么

不是只看价格，而是看**四条线**：

| # | 线 | 关键判断 |
|---|---|---|
| 1 | 品牌谱系 | 顶级制表 / 传统名表 / 独立制表 / 时装表 / 智能表 |
| 2 | 机芯 | 自动机械 / 手动机械 / 石英 / Spring Drive / 陀飞轮 |
| 3 | 风格 | 正装 / 运动 / 潜水 / 珠宝 / 复杂功能 |
| 4 | 审美参数 | 表径、厚度、表盘颜色、表带、金属色 |

表既是工具也是风格表达，与穿搭 / 配饰联动看。

## 5 种机芯类型

| 机芯 | 原理 | 优势 | 维护 |
|---|---|---|---|
| 自动机械 | 摆陀 + 发条 | 工艺感、表文化核心 | 需佩戴或摇表器 |
| 手动机械 | 手动上链 | 薄、纯机械感 | 每日/隔日上链 |
| 石英 | 电池 + 石英振荡 | 准、便宜、低维护 | 2–3 年换电池 |
| Spring Drive | 机械 + 电子调速 | 顺滑秒针、月误差 ±1s | 类似机械 |
| 陀飞轮 | 旋转擒纵补偿 | 工艺收藏 | 高端工艺款 |

## 审美参数 & 4 档预算

**审美参数**：

| 维度 | 速记 |
|---|---|
| 表径 | 手腕细选 36–38mm，粗犷选 40–44mm |
| 厚度 | 正装要薄（<10mm），运动可厚 |
| 表盘 | 白 / 黑 / 蓝百搭，绿 / 特殊色更个性 |
| 表带 | 皮带优雅、金属链耐用、橡胶运动 |
| 金属色 | 钢 / 金 / 玫瑰金，与肤色衣橱一致 |

**4 档预算**：

| 档位 | 价格 | 代表 |
|---|---|---|
| 入门机械 | 1k–5k | 精工、浪琴入门、卡西欧 |
| 中端 | 5k–3w | 浪琴、欧米茄 |
| 高端 | 3w–15w | 劳力士、卡地亚、积家 |
| 收藏级 | 15w+ | 百达翡丽、AP、江诗丹顿、RM |

## 互动工具说明

[watch-guide.html](watch-guide.html) 单文件 HTML，5 模块：

| 模块 | 作用 |
|---|---|
| 🔍 选表向导 | 预算 + 风格 + 场景 → 筛选匹配品牌 |
| ⌚ 品牌库 | 13 品牌全卡片 |
| ⚙ 机芯课堂 | 5 大机芯类型详解 |
| 💛 想表清单 | 本地收藏，标记「想了解 / 喜欢 / 无感」 |
| 💡 知识卡 | 风格 / 审美参数 / 预算 / 研究路线 |

清单与标记**只在浏览器 localStorage** 保存。

## 文件结构与设计

```
watch-guide/
├── watch-data.js     # 数据层：13 品牌 + 5 机芯 + 5 风格 + 审美参数 + 预算
├── watch-engine.js   # 纯逻辑引擎：预算/风格/场景筛品牌 + 想表清单（无 DOM 依赖、可 Node 测试）
├── watch-guide.html  # 单文件前端：选表/品牌库/机芯课堂/想表清单/知识卡
└── README.md         # 本指南
```

引擎与数据层均可在 Node 下直接 `require`，前端零依赖。
